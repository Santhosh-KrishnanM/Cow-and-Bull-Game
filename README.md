Cow and Bull Game

A web-based implementation of the classic “Cows and Bulls” number-guessing game.

🎮 Game Description

In this game:
◦ The computer chooses a secret 4-digit number (digits are unique).  
◦ The player tries to guess the number.  
◦ For each guess, feedback is given:  
 ◦ A “Bull” means a correct digit in the correct position.  
 ◦ A “Cow” means a correct digit but in the wrong position.  
◦ The goal is to guess the exact secret number in as few attempts as possible.

🧩 Features

◦ Browser-based interface (HTML + CSS + JavaScript + jQuery).  
◦ Responsive design via Bootstrap.  
◦ Real-time feedback of cows and bulls after each guess.  
◦ Keeps track of the number of attempts.  
◦ Simple and intuitive UI — enter your guess, submit, view results.

🛠️ Technologies Used

◦ HTML5  
◦ CSS3 (custom + Bootstrap framework)  
◦ JavaScript / jQuery (for game logic & UI interaction)  
◦ Bootstrap 4/5 (for styling and layout)

📂 Project Structure

◦ `index.html` → Main game page  
◦ `bootstrap.css` → Local/bootstrap stylesheet  
◦ `jquery-3.7.1.min.js` → jQuery library
